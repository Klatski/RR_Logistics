RR Logistics — Система учёта поездок

Что это

Корпоративная PWA для управления автопарком. Водители берут машины, фиксируют одометр и фото, заправляются — всё попадает в базу. Администратор видит всё в реальном времени.

База данных

Таблицы

users — водители и администраторы
id, name, login, password_hash, role,
trips — поездки
id, driver_id, car_id, odometer_start, odometer_end, distance,
start_time, end_time, start_photo_url, end_photo_url, comment, status
status: active | completed

refuels — заправки (привязаны к поездке)
id, trip_id, liters, amount, fuel_photo_url, receipt_photo_url, created_at

---
API Endpoints

Авторизация

POST   /api/auth/login       — вход (логин + пароль → JWT)
GET    /api/auth/me          — текущий пользователь
PUT    /api/auth/profile     — обновить имя, аватар, пароль

Машины

GET    /api/cars             — список всех машин
GET    /api/cars/:id         — одна машина + статистика
POST   /api/cars             — создать (admin)
PUT    /api/cars/:id         — обновить (admin)
DELETE /api/cars/:id         — удалить (admin)

GET    /api/trips/:id        — одна поездка
POST   /api/trips/start      — начать поездку
POST   /api/trips/:id/finish — завершить поездку
PUT    /api/trips/:id        — редактировать (admin)

Заправки

GET    /api/refuels          — все заправки с фильтрами (admin)
PUT    /api/refuels/:id      — редактировать (admin)

Дашборд

GET    /api/dashboard        — метрики + последние поездки (с фильтром дат)

Водители

GET    /api/drivers          — список водителей (admin)
POST   /api/drivers          — создать водителя (admin)
PUT    /api/drivers/:id      — обновить (admin)
POST   /api/drivers/:id/reset-password — сбросить пароль (admin)
DELETE /api/drivers/:id      — удалить (admin)

Файлы

POST   /api/uploads          — загрузить фото → Supabase Storage → вернуть URL
DELETE /api/uploads/:filename — удалить фото

Функциональность

Для водителя

Экран машин
- Карточки с фото, статусом (зелёный/красный/жёлтый бордер), текущим пробегом
- Недоступные машины отображаются серыми снизу списка
- Кнопка обновить

Начало поездки
- Ввод показания одометра
- Фото одометра (обязательно)
- Проверка: нельзя ввести пробег меньше текущего

Активная поездка
- Таймер на весь экран (без прокрутки)
- Показание одометра на старте
- Кнопка завершить

Завершение поездки

Дашборд
- Метрики: всего машин, активных поездок, пробег, расходы на топливо
- Фильтр периода: этот месяц / прошлый месяц / произвольный диапазон
- Таблица последних 5 поездок

Журнал поездок
- Фильтры: водитель, машина, период (from/to)
- Таблица с пагинацией до 500 записей
- Кнопка деталей → модалка с фото, маршрутом, данными заправки
- Кнопка редактирования → корректировка конечного одометра и комментария

Отчёт по заправкам
- Фильтры: машина, период
- Итоговые метрики: общая сумма, общие литры
- Таблица с кнопкой редактирования каждой записи

Машины
- Создание, редактирование, удаление
- Загрузка фото прямо в форме редактирования
- Статус, госномер, одометр

Водители
- Создание, редактирование, удаление
- Сброс пароля

---
PWA / Офлайн

- Устанавливается на телефон как нативное приложение
- Service Worker кэширует статику и API-ответы (NetworkFirst, 24 часа)
- Фото, сделанные офлайн, сохраняются в IndexedDB как blobs
- При восстановлении интернета (online событие + visibilitychange) — автосинхронизация очереди
- Фото сжимаются на клиенте до отправк
- Гонка при захвате машины исключена через SELECT ... FOR UPDATE в PostgreSQL транзакции
- Двойное бронирование невозможно на уровне бэкенда

Запуск локально

# Бэкенд
cd backend
npm install
# создай .env с DATABASE_URL, JWT_SECRET, SUPABASE_URL, SUPABASE_SERVICE_KEY
npm run dev   # :4000

# Фронтенд
cd frontend
npm install
npm run dev   # :5173 (прокси /api → :4000)

Дефолтный аккаунт администратора: admin / admin123
